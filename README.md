# Student Management System

Full Stack Student Management System built using:

- Node.js
- Express.js
- PostgreSQL
- Prisma ORM
- React.js
- Tailwind CSS

---

## Features

- Student CRUD
- Marks Management
- Pagination
- REST APIs
- Prisma ORM
- PostgreSQL Relations
- Responsive Dashboard
- Error Handling
- Validation Middleware

---

## Backend Setup

```bash
cd backend

npm install

npx prisma generate

npx prisma migrate dev

npm run dev
